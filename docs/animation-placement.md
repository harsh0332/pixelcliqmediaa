# Animation placement

Reviewed all 24 SVG animations plus three HTML viewers and their GLB models in public/animations/files. Original files remain unchanged.

- Home hero: first-click-to-checkout animation, cobalt background.
- Home growth explainer and D2C service: connected growth loop, acquisition cost, retention value.
- Five-stage process: supplied Discover, Strategise, Create, Launch and Refine animations replace the previous generic orbit.
- Creative: creative testing and ad/store/follow-up connection; optional interactive product scene.
- Shopify: product-page conversion, abandoned-cart journey, order verification; optional product scene.
- Automation: WhatsApp sales agent, post-purchase retention, COD call verification and cart recovery.
- Data: weekly reporting, profit waterfall, lifetime-value calculation and customer segmentation.
- Performance: ROAS and acquisition cost; optional interactive rocket.
- SEO: discovery and strategy animations.
- Social: creative testing and audience segmentation.

Each animated figure has a pause control, uses a frozen SVG while outside the viewport, and respects reduced-motion preferences. Numbers within supplied diagrams are explicitly presented as illustrative workflow examples rather than client outcomes. 3D viewers load only after a user opens them. The existing supplied HTML viewers use pinned Three.js CDN imports.

The pure sales-surge and revenue-milestone rocket SVGs are not placed, because the more explanatory workflows provide clearer context. The heavier compound-loop 3D scene is retained as an available source asset; the two-dimensional loop is used for readability.

Six campaign videos restored in the video edit with no visible reference heading or source-credit text. All 28 supplied AI videos remain in their collection. Featured carousel uses a portrait Baritone reveal instead of the landscape jewellery film.
